AI Agent RoboCar
讓語言模型開車的學習航線

從感測器到大腦：先在瀏覽器裡操控虛擬小車，看懂 Agent 如何「感知 → 思考 → 行動」，再動手組裝真實 RoboCar。

2. 系統架構：四層分工

點選每一層，看它負責什麼。重點是：LLM 不直接控制馬達，只透過「工具」下達高階指令。

3. 工具呼叫：把車子包成函式

Agent 能做的事，等於你定義的工具。下面是給 LLM 的工具描述，模擬器的「語言指令」模式就是用同樣的概念執行。

[
 {"name":"move_forward",
  "description":"前進 n 格，遇牆會停",
  "parameters":{"n":"integer"}},
 {"name":"turn",
  "description":"原地轉向",
  "parameters":{"dir":"left|right|back"}},
 {"name":"read_distance",
  "description":"讀取前/左/右距離",
  "parameters":{}},
 {"name":"stop","parameters":{}}
]
使用者說
前進 3 格，右轉，前進 2 格
LLM 輸出
move_forward(3) → turn(right) → move_forward(2)
小車回報
每個工具都回傳 Observation，例如「前方 0 格，撞牆」，LLM 再依此修正計畫。

4. 動手做：從虛擬到真實

建議依序完成，每一步都能獨立驗證。

硬體清單
  • ESP32 開發板（Wi-Fi 連線）
  • 雙馬達驅動板 + 兩輪底盤
  • HC-SR04 超音波感測器（前／左／右）
  • 電池與穩壓模組
實作階段
先讓馬達前進、後退、轉彎
讀取超音波，在序列埠印出距離
寫成 HTTP API：/forward、/turn、/distance
在電腦端用 LLM 呼叫這些 API，形成 Agent 迴圈
安全提醒
  • 每個動作設定逾時，斷線就停車
  • 前方距離過近時，由車上韌體直接煞車，不等 LLM
  • 先把車架高輪子再測試
